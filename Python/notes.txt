Pillars of Object Oriented Programming:
1)Inheritance:- it is a fundamental concept in oop because of which the child class is able to inherit the properties or attributes and functionalities of parent class into the child class. No need to create a new blueprint from scratch. parent class blueprint could be used and some new features or attributes could be added that differs it from parent class. improves code reusability.
In python, we have 3 types of inheritance:
i)Single Inheritance---->the attributes and functionalities from one parent class will inherit into one child class.
ii)Multilevel Inheritance---->The properties or methods and attributes of grandparent class can be inherited by parent class then the properties of parent class will be inherited by the child class.(in hierarchial manner)
iii)Multiple Inheritance----->The properties of two parent class or multiple parent class will get inherited into the child class.
2)Polymorphism :- "Many forms", in OOP, it allows objects of different classes as if they are the object of the same class and it enables reusability and makes programs more flexible. basically method defined in parent class could have different implementation in child class. so single method could have different forms and this is only polymorphism.
Types of Polymorphism:
i)Method overriding--->also called as runtime polymorphism, a child class provides a specific/different implementation of a method that has already been defined into the parent class. This allows dynamic selection at runtime.
ii)Method overloading---->also called as compile time polymorphism
iii)Operater overloading
3) Encapsulation:- It is a way of wrapping data(Variables and methods) inside a capsule or class as a single unit. It restricts the direct access to some of the object component's which is a means of preventing accidental inference or misuse of the data.
Key Concepts of Encapsulation:-
i)Private Members--->A private member is not accessible outside the class and not even in the derived class.In order to have the access over these members or to bring some modification in these members we use getter or setter method. these are declared by using double underscore before the name.(just like archives on insta)
ii)Protected Members---> it is not accessible outside the class but it is accessible by the derived or child class.(just like close friends on insta) we use single underscore before the attribute.
iii)Public Members---->A public member is accessible from anywhere or the attributes are accessible outside the class(like iron.name is directly declared outside the class. the declaration doesn't require to be done within the class unit) and these members are accessible by the derived class. Public member attribute is directly declared(ex self.name, so in this name is directly declared without any underscore or anything)(just like public story on insta)
iv)getter and setter methods---->getter method will help us out with accessing the private data. setter method is used for modifying our private data.
dir()---->it takes the input as the object name and gives us the idea that which member is public or protected or private.
4)Abstraction:- It is the concept of hiding the implementation details and only showing the necessary features of the object. This helps in reducing programming complexity and effort. It is like abstract in books, shows the basic info not the complete one. It allows us to work with an object with what an object does rather than how it does it. Like in case of function, we were looking into the implementation but in case of print we just bothered about the role of it not the implementation.
i)Abstract class--->import from ABC module. we can't create the object for this class. it cannot be instantiated.
ii)Abstract method---> it can't be accessed by the object of abstract class that's why we have to call this abstract method in child class and the implementation of abstract method is not provided inside the abstract class,bcoz object cannot be created in abstract class but must be provided in the child class. The abstract method is being defined by @abstractmethod.
Magic Methods are also called as dunder methods because they have double underscores before and after their name. they are special methods in python that allow us to customize how object behave. we can apply operations on methods like arithmetic, greater than equal to. init is also a magic method that instantiate the object with given attributes.
These methods can help us define:
i)Object Initialization(__init__)
ii)String representation(__str__,__repr__)
iii)Arithmetic Operations we can perform(__add__,__sub__)
iv)Comparison Operations(__eq__)
v)Length,indexing,iteration(__len__,__getitem__)
Why to use magic methods? It makes objects behave like built in types(list,integers),improves the readibility by allowing intuitive operations or basic operations like object1+object2, it simplifies code by replacing verbose function calls with natural syntax.

It improves code readibility by using natural syntax like obj1+object2 insted of object1.add(object2)
Every operater has a specific magic method to change or overload it's implementation to something else as per our need to play with the objects and this is only operater overloading.
